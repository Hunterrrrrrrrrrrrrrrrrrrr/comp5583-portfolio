QueryPilot

A slow-query diagnosis agent with RAG and tool calling

Purpose
Bring SQL, execution plans, schema and documentation evidence together to investigate slow queries.
My contribution
  • Agent orchestration. Built a budgeted tool loop with evidence-grounded verification.
  • Retrieval. Combined BM25 with embedding search.
  • Safe validation. Added LangGraph human approval, checkpoint recovery and read-only MySQL rewrite-equivalence tools.
Validation & boundaries

The repository documents local benchmarks and real-model tool runs on public sample data with maintainer-authored queries. These are controlled project tests; production benefits and independent expert accuracy remain unverified.

02Undergraduate thesis

LoRA on Spot Instances

Scheduling multi-tenant inference under interruptions

Purpose
Study the trade-off between latency, adapter-cache reuse and cost when serving multiple LoRA adapters on a mix of Spot and On-Demand instances.
My contribution
  • System modelling. Built a discrete-event simulator with request arrivals, LRU adapter caches and Spot interruptions.
  • Experiments. Compared four scheduling strategies across workloads, ablation and interruption-sensitivity experiments.
  • Mechanism validation. Added a Linux worker prototype for retry and fallback after worker termination.
Findings & boundaries

The thesis reports benefits from cache-aware scheduling under high adapter reuse, with smaller gains when queueing dominates. The worker prototype uses simulated task durations; it does not establish real GPU inference performance or production cloud savings.
